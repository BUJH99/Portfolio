# 이미지 출처와 참고 문헌

그림은 기존 학습자료에서 가져오거나 이를 재구성한 **참고 도식**이다. 확인된 파일 유래와 기술 개념의 참고 문헌을 아래에 구분했다. 이미지 파일의 최초 제작자는 확인되지 않았으며, 포트폴리오 작성자의 직접 제작물로 표기하지 않는다.

| 자료 | 확인된 파일 유래 | 기술 개념의 참고 문헌 |
| --- | --- | --- |
| [UVM OOP](./Seminars/UVM/images/uvm-oop-concepts-explained.svg) | 기존 OOP 설명 PNG를 SVG로 재구성한 기록 확인 | Ray Salemi, *The UVM Primer*, Ch. 4–6. [저자 예제 저장소](https://github.com/raysalemi/uvmprimer) |
| [UVM Library](./Seminars/UVM/images/uvm-library-services.svg) | 기존 Library PNG를 SVG로 재구성하고 phase·factory 설명을 수정한 기록 확인 | Accellera, [UVM 1.2 Class Reference](https://www.accellera.org/images/downloads/standards/uvm/UVM_Class_Reference_Manual_1.2.pdf): object, reporting, factory, phase, config_db, objection |
| [UVM handshake](./Seminars/UVM/images/uvm-handshake.png) | 기존 학습 문서의 첨부 PNG와 SHA-256 일치. 최초 제작자 미확인 | Accellera, [UVM 1.2 User's Guide §3.5.1](https://www.accellera.org/images/downloads/standards/uvm/uvm_users_guide_1.2.pdf#page=42) |
| [UVM Analysis Port](./Seminars/UVM/images/uvm-analysis-port.png) | 기존 학습 문서의 첨부 PNG와 SHA-256 일치. 최초 제작자 미확인 | Accellera, [UVM 1.2 User's Guide §2.3.3](https://www.accellera.org/images/downloads/standards/uvm/uvm_users_guide_1.2.pdf#page=20) |
| [AXI channels](./Seminars/AXI4/images/axi-channel-interconnect.svg) | 기존 학습 문서의 채널 구조 PNG를 SVG로 재구성한 기록 확인 | Arm, [IHI 0022H §A1.2](https://developer.arm.com/-/media/Arm%20Developer%20Community/PDF/IHI0022H_amba_axi_protocol_spec.pdf#page=27) |
| [AXI handshake dependencies](./Seminars/AXI4/images/axi-handshake-dependencies.svg) | 제공된 도식을 재구성한 SVG. 메타데이터에 Arm 사양서의 참조 그림 번호 명시 | Arm, [IHI 0022H §A3.3, Fig. A3-5·A3-7](https://developer.arm.com/-/media/Arm%20Developer%20Community/PDF/IHI0022H_amba_axi_protocol_spec.pdf#page=45) |
| [AXI memory attributes](./Seminars/AXI4/images/axi-memory-attributes.svg) | 기존 AWCACHE·ARCACHE PNG 두 개를 통합·재구성. 원본 PNG는 기존 학습 문서 첨부와 SHA-256 일치 | Arm, [IHI 0022H §A4.3–A4.4](https://developer.arm.com/-/media/Arm%20Developer%20Community/PDF/IHI0022H_amba_axi_protocol_spec.pdf#page=65) |

참고 문헌은 개념·규칙을 확인하는 근거다. 해당 문헌의 저자를 현재 이미지 파일의 제작자로 단정하는 표시는 아니다. 기존 자료를 SVG로 옮기거나 편집한 사실만으로 최초 제작자를 판단하지 않는다.

Exclusive access는 그림 대신 [Arm IHI 0022H §A7.2](https://developer.arm.com/-/media/Arm%20Developer%20Community/PDF/IHI0022H_amba_axi_protocol_spec.pdf#page=96)를 연결한다.

[파일별 복사 기준과 SHA-256](./docs/source_manifest.json). `source`는 포트폴리오로 복사한 직전 파일의 위치이며 원저작자 표시가 아니다. 상세 대조 기록과 원본 학습 문서는 로컬에 보관한다.
