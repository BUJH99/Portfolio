# ⚗️ CMOS LDO 공정 흐름 설계

## 📅 프로젝트 정보

- **수행**: 2024년 · 반도체 및 디스플레이 공정 팀 프로젝트
- **본인 담당**: 전체 Process Flow 설계·검토, Cross-Section View 구성
- **주제**: 7T2C LDO의 소자·배선·커패시터 구조와 제조 공정 연결

## 🔑 주요 내용

- 세정·소자 분리·Well·Gate·LDD·Source/Drain·다층 배선의 공정 순서 구성
- 3 μm 설계 규칙과 1 μm 정렬 허용오차를 반영한 단면 검토
- **118 × 100 μm** 배치와 전극 공유 MIMIM 커패시터 구조 설명
- 최종 배치·계산 기준 **Cc=0.5 pF, CL=1 pF** 확인
