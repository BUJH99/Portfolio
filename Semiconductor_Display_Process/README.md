# ⚗️ CMOS LDO 공정 흐름 설계

## 📅 프로젝트 정보

- **수행**: 2024년 · 반도체 및 디스플레이 공정 팀 프로젝트
- **본인 담당**: 전체 Process Flow 설계·검토, Cross-Section View 구성
- **설계 대상**: 7T2C CMOS LDO · NMOS 4개, PMOS 3개, 커패시터 2개
- **주제**: 회로·Layout·소자 단면을 연결하는 CMOS 제조 공정 흐름 설계

## 📝 프로젝트 개요

7개의 트랜지스터와 2개의 커패시터로 구성된 LDO 회로를 대상으로, 소자 형성부터 다층 금속 배선까지의 공정 순서와 각 단계의 단면 구조를 설계했습니다.

회로의 소자 연결을 Layout에 배치하고, 마스크·증착·식각·이온 주입 과정에 따라 구조가 어떻게 형성되는지 Cross-Section View로 표현했습니다. 커패시터는 전극을 공유하는 MIMIM 적층 구조를 적용해 배치 면적을 줄이는 방향으로 구성했습니다.

## 🔑 주요 내용

- **공정 순서 설계**: 웨이퍼 세정 → 소자 분리 → Well → Gate → LDD → Source/Drain → 접촉부·다층 배선으로 이어지는 흐름을 구성했습니다.
- **공정별 단면 구성**: 마스크 영역과 재료층의 변화를 단면으로 표현하고, 소자 형성 과정과 배선 연결을 검토했습니다.
- **설계 규칙 반영**: 최소 설계 규칙, 정렬 허용오차, 식각 바이어스를 고려해 Layout과 단면 구조를 구성했습니다.
- **커패시터 적층**: 금속 전극을 공유하는 MIMIM 구조로 **5개 전극층에 4개 병렬 커패시터**를 구성하고, 유전체 두께와 전극 면적을 계산했습니다.

## 📐 설계 조건

| 항목 | 설계값 |
|---|---|
| 최소 설계 규칙 | **3 μm** |
| 첫 번째 층 기준 정렬 허용오차 | **1 μm** |
| 금속층 식각 바이어스 | 면당 **1 μm** |
| 반도체·유전체층 식각 바이어스 | 면당 **0.5 μm** |
| Layout 크기 | **118 × 100 μm** |
| 커패시터 | **Cc = 0.5 pF · CL = 1 pF** |
