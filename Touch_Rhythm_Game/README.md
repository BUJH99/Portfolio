# 🎮 터치식 리듬게임 · Python 실행본 복구

## 📅 프로젝트 정보

- **수행**: 2024.04 ~ 2024.05
- **현재 공개 코드**: `Python` · `pygame-ce` · `Pillow`

## 📝 프로젝트 개요

원본 압축파일에 있던 4-key 리듬게임을 복구했습니다. 노트 생성·시간 판정·콤보·Fever·점수 로직을 유지하고, 별도 음악이나 폰트 없이 실행되는 자체 데모 자산을 추가했습니다.

## ✅ 실행 확인

- 32개 노트 로드, 게임 화면 **300프레임** 진행
- 키 입력 판정·점수 증가·음원 재생 시작 확인
- 키보드 **D / F / J / K**, 곡 선택 **↑ / ↓**, 시작 **Space**, 종료 **Esc**
