# 📘 ChipBook

## 📝 프로젝트 개요

디지털 회로설계와 반도체 시스템 학습 내용을 주제별로 정리한 웹 가이드북입니다. 학습 페이지, 도식과 문제 풀이를 한 곳에서 탐색할 수 있도록 구성했습니다.

## 🔑 주요 구성

- RTL·Frontend·Physical Design·Memory의 설계 흐름
- UVM 검증, On-Chip Bus와 Off-Chip Interface
- MOS 구조와 회로 도식, AI Accelerator 개념
- 개념별 학습 페이지와 예상·모의 문제
